# Skill Trainer

Skill Trainer is part of Action Queue now. Everything it did (the Train window, every skill, combat, Agility building, Farming and the rest) is in [Action Queue](https://github.com/Druidperson/Action-Queue) 2.0.0 and later.

Install Action Queue and uninstall this mod. This last version doesn't do anything except remind you.
